# 폰 목업 스튜디오

스크린샷을 iPhone 17 Pro Max / Galaxy S26 Ultra 프레임에 합성해 PNG로 저장하는 도구입니다.
빌드 과정이 없는 단일 HTML 파일이라, GitHub Pages에 그대로 올리면 PC와 휴대폰 모두에서 열립니다.

## 쓰는 법

- **PC** — 스크린샷을 끌어다 놓거나 `Ctrl/⌘+V`로 붙여넣고, 오른쪽에서 기기·색상·배경을 고른 뒤 저장합니다.
- **휴대폰** — 하단 바의 `사진 선택`으로 사진첩에서 여러 장을 고르고, `저장`을 누릅니다.
  - 공유 시트가 열리면 `이미지 저장`으로 사진첩에 바로 들어갑니다.
  - 공유 시트를 지원하지 않는 브라우저에서는 완성본이 화면에 뜨고, 이미지를 길게 눌러 저장합니다.

## 로컬에서 열기

`index.html`을 브라우저로 열면 끝입니다. 서버가 필요 없습니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 도구 전체 (HTML·CSS·JS·기기 프레임 SVG가 한 파일에 들어 있음) |

기기 프레임은 외부 이미지가 아니라 코드로 그리는 SVG입니다. 새 기기를 추가하려면
`index.html`의 `DEVICES` 객체에 `vb`(뷰박스) · `body`(몸체) · `screen`(화면) 좌표와
색상 목록을 같은 규약으로 넣으면 됩니다.
