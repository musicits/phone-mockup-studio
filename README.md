# 폰 목업 스튜디오

스크린샷을 아이폰·갤럭시 프레임에 합성해 PNG로 저장하는 도구입니다.
빌드 과정이 없는 단일 HTML 파일이라, GitHub Pages에 그대로 올리면 PC와 휴대폰 모두에서 열립니다.

## 지원 기기

| 브랜드 | 모델 |
| --- | --- |
| 아이폰 | 18 Pro Max · 18 Pro · 17 Pro Max · 17 Pro · Air · 17 · 17e · SE (3세대) · 8 Plus |
| 갤럭시 | S26 Ultra · S26+ · S26 · S26 FE |

색상 이름은 애플·삼성 한국 공식 표기를 따릅니다.

## 쓰는 법

- **PC** — 스크린샷을 끌어다 놓거나 `Ctrl/⌘+V`로 붙여넣고, 오른쪽에서 아이폰/갤럭시 → 모델 → 색상·배경을 고른 뒤 저장합니다.
- **휴대폰** — 하단 바의 `사진 선택`으로 사진첩에서 여러 장을 고르고, `저장`을 누릅니다.
  - 공유 시트가 열리면 `이미지 저장`으로 사진첩에 바로 들어갑니다.
  - 공유 시트를 지원하지 않는 브라우저에서는 완성본이 화면에 뜨고, 이미지를 길게 눌러 저장합니다.

## 로컬에서 열기

`index.html`을 브라우저로 열면 끝입니다. 서버가 필요 없습니다.

| `index.html` | 도구 전체 (HTML·CSS·JS·기기 프레임 SVG가 한 파일에 들어 있음) |

## 새 기기 추가

기기 프레임은 외부 이미지가 아니라 코드로 그리는 SVG입니다. `index.html`의 `DEVICES`에
`phone({...})` 한 줄을 넣으면 됩니다. 공식 사양표의 숫자만 있으면 됩니다.

- `mm` — 본체 가로·세로(mm)
- `diag` — 화면 대각선(인치, 둥근 모서리를 사각형으로 쟀을 때 값)
- `modes` — 화면 해상도(첫 번째가 권장 스크린샷 크기)
- `cut` — 전면 카메라: `island`(다이내믹 아일랜드) · `notch` · `hole`(펀치홀) · `home`(홈 버튼)
- `colors` — 테두리 금속 색 목록

화면 위치와 베젤은 이 값에서 자동으로 계산됩니다.
